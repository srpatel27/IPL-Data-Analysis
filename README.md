# 🏏 IPL Data Analysis

## 📌 Overview
Analysis of IPL matches from 2008-2020 using Python & Tableau.

## 🛠️ Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Tableau Public

## 📊 Key Findings
- Mumbai Indians won the most matches
- Virat Kohli is the top run scorer
- Toss winner wins 51% of matches
